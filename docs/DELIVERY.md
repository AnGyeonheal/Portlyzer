# Portlyzer 구현 및 검증 결과

작성일: 2026-10-02. 초기 README만 있던 저장소에 실제 동작하는 전체 애플리케이션을 구현했다.
Portseido 공개 기능의 확인 여부는 [기능 대응표](FEATURE_MATRIX.md)에 별도로 구분했다.

## 현재 실행 상태

- 이 작업 환경의 프로덕션 앱: **http://127.0.0.1:3100**
- 별도로 초기화한 로컬 PostgreSQL: 루프백 **55432** 포트, PostgreSQL **17.10**.
- 앱과 DB를 모두 실제 종료/재시작한 후 기존 세션, 계좌, 원장, 수정 가격과 NAV 유지 확인.
- 로컬 `.env`, DB 데이터, 브라우저 인증 상태는 Git 추적 대상이 아니다.
- **커밋·푸시를 수행하지 않았다.** 사용자의 계정 제한 요청을 반영해 계정
  혼동이 없도록 변경 사항과 lockfile을 현재 작업트리에 보존했다.

일반적인 새 환경 실행은 [README](../README.md)의 기본 3000 포트/Compose 절차를 따른다.
이 환경의 3100/55432는 기존 프로세스와 충돌하지 않도록 선택한 로컬 검증 포트다.
백그라운드 실행 프로세스는 이 작업에서 생성한 것만 관리했다.

가격 벤치마크는 배당 재투자 총수익 지수가 아니다. 총수익 지수 제공은 미구현이며,
현재 제공되는 비교는 배당 처리 기준을 맞춘 **별도의 배당 제외 수익률**을 사용한다.
외부 관측의 완전성, 무료 실시간성, 정확성 또는 가용성을 보장하지 않는다.

## 실제 실행한 최종 검증

검증 환경: Windows, Node **24.21.0**, PostgreSQL **17.10**, Next.js **16.3.8**,
Prisma **6.19.3**, Vitest **5.0.3**, Playwright **1.63.0 / Chromium**.

| 실행 | 결과 |
| --- | --- |
| `npm ci` | 성공. lockfile 기준 588 패키지 새 설치 및 postinstall Prisma Client 생성 |
| `prisma migrate deploy`, `prisma migrate status` | 최초 마이그레이션 적용, 실제 PostgreSQL 스키마 일치 |
| `npm run typecheck` | 성공 |
| `npm run lint` | 성공, 오류/경고 0 |
| `RUN_INTEGRATION=1`, `RUN_NETWORK_TESTS=1`로 `npm test` | **15 파일, 401 테스트 통과** |
| `npm run build` | 최종 프로덕션 컴파일·타입 확인·페이지 생성·standalone 출력 성공 |
| `npm audit --audit-level=moderate` | 알려진 취약점 **0**. 이것은 보안 무결성 보증을 뜻하지 않음 |
| `npm run test:e2e` | **2 테스트 통과**, 별도 재시작 테스트 1개는 의도적으로 분리 |

| 최종 빌드 대상으로 E2E 재실행 | **2 테스트 재통과**, 임시 브라우저 인증 파일 제거 |

| 프로덕션 클라이언트 산출물 검사 | 정적 파일 **19개**에서 로컬 DB 접속 URL·인증 비밀키 원문 미검출. 민감한 값은 출력하지 않음 |
| 실제 FX 호출 | ECB 관측 **2024-01-02 USD/KRW = 1313.23** 확인. 이 환경은 시스템 프록시/CA 옵션 사용 |
| CI/Compose YAML 파싱 | 성공. 컨테이너 실제 실행 또는 원격 CI 통과로 간주하지 않음 |

단위·통합 기대값은 구현 함수를 다시 호출해서 만든 값만 사용하지 않았다.
수작업 금액과 독립적인 사례로 부분 매도/수수료/세금/배당/환전/분할/기간 중 입출금/
계좌 경계 이동/미분류·가격 누락/여러 XIRR 해/역환율 정밀도를 확인했다.

### 브라우저에서 검증한 사용 흐름

1. 신규 회원가입 → 계좌 생성 → CSV 업로드 → 잘못된 수량 행 수정 → 검증 → 미리보기 → 확정.
2. 시세 등록 후 NAV **5,272.25 USD**, 총손익 **272.25 USD**.
3. 동일 파일 재업로드 거절, 원장 4건 유지.
4. 매수 단가 180→181 변경 후 NAV **5,262.25 USD**, 원본/수정 이력 보존.
5. 배당 삭제 후 NAV **5,258 USD**, 유효 거래 3건, 원본/내보내기 거래는 4건 유지.
6. 가격 유효 기간 초과 시 NAV `null`과 관측일/오류 표시, 데모 대체 없음.
7. 다른 사용자로 계좌 수정·감사 이력·계좌 필터 접근 거절, 다른 사용자 원장 비노출.
8. JSON 내보내기에 비밀번호/세션 토큰 없음, 잘못된 Origin/과대 인증 요청 거절.
9. 새로고침·로그아웃·재로그인·실제 앱/DB 재시작 후 보존.
10. 별도 데모 로그인 및 모든 메뉴, 데스크톱/모바일 렌더링.

### 발견하여 해결한 항목

- 목표 계산의 배열/상세 결과 계약 혼동: API 응답 형태를 고정하고 회귀 검증.
- 빈 포트폴리오 선택이 전체 계좌로 확대되는 엔진 기본값: API 경계에서 빈 원장 처리.
- 반대 방향 수동 FX 우선순위와 역수 선반올림: 원래 방향/수치 보존 후 정확한 나눗셈.
- 큰 금액의 IEEE-754 정수 손실과 큰 값 상쇄 시 표시 합계 오차: Decimal/BigInt 기반 표시.
- CSV 의존성 및 transitive advisory: 검증된 고정 버전/좁은 override, XLSX/Prisma 재검증.
- Windows Prisma DLL 잠금: 설치 후/명시적 생성으로 분리, 타입 검사에서 재생성 제거.
- 동일 worktree의 복수 Next dev 충돌: 소유 프로세스를 조율하고 최종 프로덕션 서버로 검증.

관련 재발 방지 사항은 [프로젝트 지침](../.github/instructions/portfolio.instructions.md)에 기록했다.

## 다음 환경에서 필요한 작업

1. Node 24, Docker 또는 PostgreSQL을 준비하고 [실행 안내](../README.md)를 따른다.
2. HTTPS 공개 배포, 비밀키 발급, 유료/상업용 데이터 권리 확인은 운영자가 수행한다.
3. 가격/배당/기업행동 자동 제공 범위를 확장하려면 공식 문서와 이용 권리를 먼저 확인한다.
4. 실제 증권사 샘플이 확보되면 검증 사례와 함께 전용 파서를 추가한다.
5. 원격 CI 및 Docker 기동은 준비된 환경에서 실제 실행하고 결과를 갱신한다.
6. 향후 커밋/푸시는 사용자가 원하는 Git 작성자·GitHub 계정을 명확히 확인한 후 별도로 진행한다.
