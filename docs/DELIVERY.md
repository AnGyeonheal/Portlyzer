# Portlyzer 구현 및 검증 결과

최초 작성: 2026-10-02. 배포 전 보완 및 검증: 2026-10-03~04(KST).
초기 README만 있던 저장소에 실제 동작하는 전체 애플리케이션을 구현했다.
Portseido 공개 기능의 확인 여부는 [기능 대응표](FEATURE_MATRIX.md)에 별도로 구분했다.

## 표준 엑셀 입력 보완 (2026-10-04)

- 기본 가져오기 경로를 **빈 XLSX 양식 다운로드 → 작성 → 업로드/자동 연결·검증 → 수정 → 미리보기 → 확정**으로 변경했다.
  일반 CSV/XLSX 열 매핑과 수동 입력은 유지했다.
- 양식은 단일 시트/한국어 17열, 거래 유형·통화 목록, 입력 도움말과 텍스트 서식을 제공한다.
  예시 거래는 포함하지 않으며 마지막의 빈 서식 행을 거래로 오인하지 않는다.
- 표준 모드의 열 이름/순서를 서버에서 확인하고, 고정된 입력 검사 상수만 허용한다.
  거대한 검사 범위/중첩 참조를 ExcelJS 로드 전에 차단하며 원본 행 번호·정밀도·중복 방지를 유지한다.
- 관련 단위 테스트 **164개**, 원장·가져오기 통합 테스트 **41개** 통과.
  운영용 빌드/타입/린트 통과 및 새 빌드의 **엑셀 E2E 1개, 기존 포트폴리오/데모 E2E 2개,
  별도 재시작 E2E 1개**를 검증했다. 아래 452개 전체 테스트 기록은 앞선 배포 전 보완 시점의 결과다.
- 실제 다운로드 파일을 채워 모바일에서 올린 뒤 열 연결 없이 오류 수정/확정했고,
  NAV **5,272.25 USD**, 손익 **272.25 USD**, 원본의 잘못된 수량 보존과 동일 파일 재반영 거절을 확인했다.
- 사용자별 업로드 데이터는 검증 전용 DB에서 테스트했으며 실제 사용자 거래는 추가/변경하지 않았다.
  사용 방법은 [엑셀 작성 안내](IMPORT_TEMPLATE.md)에 정리했다.

## 배포 전 보완 결과 (2026-10-03~04)

- 데모의 180일 시세와 연초 기본 조회 사이의 공백으로 발생한 **계산 제한 95건**을 재현하고
  해결했다. 계산 규칙을 완화하지 않고 최근 1년 조회/시작 전일을 포함한 DEMO 관측치를 보충한다.
  기존 데모 사용자 3명의 원장과 수정 이력을 보존하면서 누락 관측치를 보완했고 오류 0건을 확인했다.
- SMTP 이메일 인증/비밀번호 재설정, 비밀번호 변경/다른 세션 해제, 비밀번호 재확인 후
  본인 계정 탈퇴를 구현했다. 메일 미설정/만료 링크/메일 발송 실패도 별도 상태로 표시한다.
- 익명 인증 쓰기에도 Origin 검사를 적용한다. 인증 라이브러리가 흡수하는 메일 전송 실패를
  요청별로 보존해 HTTP 503으로 반환하며 동시 요청에 오류 상태가 섞이지 않도록 검증했다.
- `portlyzer.cmd`로 프로젝트 전용 Node 선택, DB 시작/마이그레이션/빌드/상태 확인/종료를 제공한다.
  PowerShell 실행 정책이나 전역 서비스를 변경하지 않았다. 인증된 로컬 제어 채널로 자기 앱만 관리한다.
- AES-256-GCM DB 백업, 변조/키 검증, 새 DB에만 복원하는 CLI와 실제 복원 검증을 추가했다.
- 운영 실행을 Next standalone으로 통일했다. 빌드 후 정적 자산을 포함하고 자동 복사된 `.env*`를
  제거하며 로컬 데이터/도구/백업은 산출물에서 제외한다.
- 공개 환경 검사, 최근 N일 갱신 CLI, 메일/복원/컨테이너 smoke CI 구성을 추가했다.
  운영 안내와 기존 프로젝트 지침에 재발 방지 사항을 기록했다.

### 현재 로컬 실행

- 앱: **http://127.0.0.1:3000**, 개발 서버가 아닌 **standalone 운영 빌드**.
- PostgreSQL **17.10**, 루프백 **5432** 포트. 기존 `.local-db`를 보존했다.
- `.\portlyzer.cmd start`, `status`, `check`, `backup`, `stop`으로 관리한다.
  상세 절차와 새 DB 복원 명령은 [운영 문서](OPERATIONS.md)에 있다.
- 실제 앱/DB 종료·재시작 후 동일 데모 세션, 거래 16건, 평가액 **41,699,774.96 KRW**와
  계산 오류 0건을 확인했다. 이는 합성 데이터의 검증값이며 실제 투자 성과가 아니다.
- 보완 전과 최종 상태의 암호화 백업을 로컬에 보관했다. 키는 별도 보관해야 한다.
- 검증 전용으로 생성한 DB와 복원 DB, 임시 연결/브라우저 인증 파일 및 테스트 보고서 파일을 정리했다.
  사용자 DB, 운영 산출물, 백업/키 및 현재 실행 상태는 유지한다.
- **공개 배포·커밋·푸시·OS 자동 실행 등록은 수행하지 않았다.**

### 공개 배포 시 운영자가 완료할 사항

1. 서버/도메인/HTTPS 프록시, 관리형 TLS DB, 운영용 비밀키를 준비하고 공개 모드 검사를 통과시킨다.
   기본 Compose는 비 TLS 로컬 DB 구성이다. 공개 환경용 실행 방식은 운영 문서를 따른다.
2. 실제 SMTP 자격 증명과 발신 도메인을 설정하고 외부 메일 수신을 확인한다. 로컬 메일 수신기
   검증은 실제 발신 서비스 계정의 가용성/스팸 분류를 보증하지 않는다.
3. 백업/갱신 스케줄·보존 기간·장애 알림 수신처·개인정보 처리방침을 운영 환경에 적용한다.
4. 가격 자동 수집에 필요한 API 키/사용 권리를 확보한다. 국내 주가/암호화폐/배당·기업행동/
   증권사 자동 연동 및 실제 증권사별 파일 샘플 검증은 여전히 별도 작업이다.
   범용 CSV/XLSX와 수동 관측은 구현·검증되어 있다.
5. Docker가 있는 환경에서 컨테이너 smoke 및 GitHub Actions를 실제 실행한다.
   현재 PC에는 Docker 실행 환경이 없어 이 부분을 통과했다고 주장하지 않는다.
6. 전체 dependency audit의 개발용 `braces <=3.0.3` 경고를 추적한다.
   [GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)는 점검 시 수정 버전이 없고
   린트 의존 경로상 **5개 HIGH 항목**으로 집계된다. 운영 의존성에는 포함되지 않는다.
   임의 Next 다운그레이드나 검증되지 않은 패치로 덮지 않았다.

MFA, Beta/Sharpe, Google Sheets 동기화 등의 선택적 확장은 이번 배포 전 보완에 포함하지 않는다.
운영 의존성 audit 통과나 자동 테스트는 보안/금융 데이터의 완전성 보증이 아니다.

| 원본 API 재동기화 | 기반 구현, 실제 증권사 미연동 | 원본/수정값 분리 및 idempotency 구조. 확인되지 않은 증권사 엔드포인트나 국내 전용 파서는 만들지 않음 |
| 추가 공개 벤치마크 기능 | 미구현 | Portseido 공개 자료의 Beta/Sharpe, Google Sheets 동기화, LIFO 등은 이번 필수 구현 범위 밖이며 지원한다고 표시하지 않음 |
| 데모 | 구현·검증 완료 | 별도 사용자/세션/합성 시세, DEMO 표시. 연초/1년 및 기초 벤치마크 관측 보완. 실사용자에 seed 불가, 장애 시 데모로 대체하지 않음 |
| 사용자 데이터 내보내기 | 구현·검증 완료 | 원장·원본·수정·분개·시장 관측·목표 전체 JSON. 인증 계정/비밀번호/세션 토큰 제외 |
| DB 백업/복원 | 구현·검증 완료 | 암호화된 전체 DB 스냅샷, 키/변조 확인 후 새 DB 복원. 기존 DB 덮어쓰기 없음. 스케줄·키 보관은 운영자 설정 |
| 스키마·마이그레이션·seed | 구현·실제 PG 검증 완료 | 최초 SQL 마이그레이션, 조건부 독립 데모 seed, 예제 CSV. 기존 데이터를 재생성하거나 운영 데이터를 삭제하지 않음 |
| CI·Docker·배포 구성 | 구성 완료, 일부 실행 미검증 | CI YAML·Compose YAML 구문 검증 완료. 로컬 Docker 실행 파일/daemon 부재로 컨테이너 빌드/기동은 미실행. GitHub Actions 원격 실행·공개 배포도 미수행 |
| 운영 인증 확장 | 구현·로컬 검증, 외부 SMTP 설정 필요 | 이메일 인증/복구·비밀번호 변경·세션 폐기·본인 탈퇴 및 다른 사용자 보존 검증. MFA/실제 SMTP/운영 알림·법적 고지는 별도 운영 구성 |

가격 벤치마크는 배당 재투자 총수익 지수가 아니다. 총수익 지수 제공은 미구현이며,
현재 제공되는 비교는 배당 처리 기준을 맞춘 **별도의 배당 제외 수익률**을 사용한다.
외부 관측의 완전성, 무료 실시간성, 정확성 또는 가용성을 보장하지 않는다.

2. 시세 등록 후 NAV **5,272.25 USD**, 총손익 **272.25 USD**.
3. 동일 파일 재업로드 거절, 원장 4건 유지.
4. 매수 단가 180→181 변경 후 NAV **5,262.25 USD**, 원본/수정 이력 보존.
5. 배당 삭제 후 NAV **5,258 USD**, 유효 거래 3건, 원본/내보내기 거래는 4건 유지.
6. 가격 유효 기간 초과 시 NAV `null`과 관측일/오류 표시, 데모 대체 없음.
7. 다른 사용자로 계좌 수정·감사 이력·계좌 필터 접근 거절, 다른 사용자 원장 비노출.

9. 새로고침·로그아웃·재로그인·실제 앱/DB 재시작 후 보존.
10. 별도 데모 로그인 및 모든 메뉴, 데스크톱/모바일 렌더링.

### 발견하여 해결한 항목

- 목표 계산의 배열/상세 결과 계약 혼동: API 응답 형태를 고정하고 회귀 검증.
- 빈 포트폴리오 선택이 전체 계좌로 확대되는 엔진 기본값: API 경계에서 빈 원장 처리.
- 반대 방향 수동 FX 우선순위와 역수 선반올림: 원래 방향/수치 보존 후 정확한 나눗셈.
- 큰 금액의 IEEE-754 정수 손실과 큰 값 상쇄 시 표시 합계 오차: Decimal/BigInt 기반 표시.
- CSV 의존성 및 transitive advisory: 검증된 고정 버전/좁은 override, XLSX/Prisma 재검증.
- Windows Prisma DLL 잠금: 설치 후/명시적 생성으로 분리, 타입 검사에서 재생성 제거.
- 동일 worktree의 복수 Next dev 충돌: 소유 프로세스를 조율하고 최종 프로덕션 서버로 검증.
